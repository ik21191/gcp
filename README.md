# GCP
This repository contains various sample applications to showcase the use of `Docker`, `Docker Compose`, `Kubernetes(k8s)` technology stacks.

## Prerequisite
Before trying to explore any of the application of this repository, make sure to install `Docker` runtime environment via `Docker Desktop` or `Rancher Desktop`.

Most of the applications are used for explanation of various concepts in this [Google Doc](https://docs.google.com/document/d/1v8Nf05LuIipxeugtWbp0kbukpJX4b7a5Rh0Xd-v5vE0/edit?usp=sharing)
